# ☕ Java Challenges & Studies — Alura & Santander DIO (2024)

Repositório unificado reunindo desafios de código, projetos práticos de Programação Orientada a Objetos (POO), consumo de APIs REST e persistência de dados com **Spring Data JPA** desenvolvidos nos bootcamps **Oracle Next Education (Alura)** e **Santander Bootcamp (DIO)** entre Abril e Junho de 2024.

> 💡 *O histórico de commits e as datas originais de Abril a Junho de 2024 foram integralmente preservados neste repositório.*

## 🛠️ Tecnologias e Conceitos Praticados

- **Java Core & POO:** Encapsulamento, Herança, Polimorfismo, Interfaces, Records, Streams e Lambdas.
- **Integração com APIs:** Requisições assíncronas/síncronas com `HttpClient`, `HttpRequest` e desserialização JSON com **Gson** e **Jackson**.
- **Persistência de Dados:** **Spring Boot**, **Spring Data JPA**, **Hibernate**, mapeamento objeto-relacional (`@Entity`, `@OneToMany`, `@ManyToOne`) e **PostgreSQL**.
